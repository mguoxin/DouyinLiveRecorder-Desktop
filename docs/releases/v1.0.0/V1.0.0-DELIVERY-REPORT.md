## 2. 功能清单（v1.0.0）

### P0 核心录制（复用 v0.5.0 基线）
- 直播间管理、开播监控、自动录制、多主播并行、异常退出恢复、FFmpeg 进程管理、解析器契约/重试/熔断、自动归档、存储管理、实时指标与健康状态。
- v0.5.0 已有 516 项测试全部保留并通过。

### P1 媒体资产
- Schema v4：`duration_s/width/height/video_codec/audio_codec/thumbnail_path/metadata_status/metadata_error/metadata_updated_at/favorite/note`。
- 后台媒体探测：优先 FFprobe；内置 FFmpeg 无 ffprobe 时解析 `ffmpeg -i`；缩略图 `.part` + 原子替换；失败写入 `metadata_status=failed` 并支持强制重试；源文件被归档清理时回退归档副本。
- 标签 CRUD 与录制关联（CASCADE）、收藏、备注、主播档案（简介/备注/头像路径）。
- 录制库：标签/收藏/时长筛选，最新/最早/最大/最小/最长/最短排序（白名单），详情面板封面与媒体信息。

### P1 自动化规则
- 规则类型：定时监控、定时录制、磁盘预警、自动归档（按房间覆盖全局）、录制后处理。
- `RuleEngine`：60 秒周期评估、事件队列、优先级冲突（数字小者优先，房间级优先于全局）、幂等（只停止自己启动的任务、同录制只处理后处理一次）、`rule_runs` 执行历史、异常退出遗留 `running` 标记失败、失败/磁盘通知。
- “自动化”页面：规则 CRUD、启用/停用、执行历史。

### P1 统计与诊断
- 总览、每日/每月、按主播、失败/中断原因、存储构成（录制/归档/缩略图/剩余空间）。
- 进程 RSS 与 CPU 采样（ctypes，无新增依赖）；统计页后台加载；JSON 统计报告导出。

### P1 系统管理
- 配置与数据库备份/恢复沿用 v0.4.x 的 SQLite 在线备份与“暂存 + 重启应用”安全恢复（恢复前自动安全副本）。
- Schema 迁移：V3→V4、V1→V4 链式；每步迁移前自动备份、事务内升级、提交后校验、失败回滚、幂等。
- 更新检查：用户显式配置清单 URL，只读版本比较；**不自动下载、不自动替换**；升级失败回滚依赖迁移备份与数据库恢复。
- 统计页展示应用版本与 Schema 版本。

### P2 架构
- 解析适配器、归档服务、媒体探测服务、规则引擎、统计服务边界清晰；未引入插件系统（当前无实际需求，避免过度设计）；通知通过注入回调解耦。

### 备份、恢复、升级与回滚
1. 备份：设置页“备份数据库”生成一致性副本；跨机器迁移可直接复制整个数据目录（`data\`），或在设置页恢复数据库。
2. 恢复：选择备份文件 → 程序暂存并在重启时应用，应用前自动保存当前库安全副本。
3. 升级：替换程序目录后首次启动自动执行 Schema 迁移，迁移前写入 `migration_backups/`。
4. 回滚：迁移失败自动回滚事务；如升级后异常，用升级前的 `migration_backups` 或用户备份通过“恢复数据库”回退。
