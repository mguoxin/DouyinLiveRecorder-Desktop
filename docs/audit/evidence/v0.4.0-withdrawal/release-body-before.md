## 抖音直播录制工具 v0.4.0（GUI 现代化正式版）

Windows 桌面版，Python + PySide6 重写界面，内置 FFmpeg，解压即用。

### 本版亮点

- **全新 GUI**：侧边栏导航（直播间管理 / 录制历史 / 日志 / 设置），支持添加与编辑直播间，深色 / 浅色 / 跟随系统主题并持久化。
- **系统托盘**：默认最小化到系统托盘，托盘菜单与双击恢复；托盘不可用或初始化异常时安全降级为普通窗口。
- **图标与版本资源**：窗口、任务栏、Alt+Tab、系统托盘、EXE 内嵌图标统一为同一品牌图形（`.ico` 含 16/20/24/32/40/48/64/96/128/256 px）；Windows 文件属性补齐 `FileVersion 0.4.0.0`、`ProductVersion 0.4.0`、`FileDescription 抖音直播录制工具`。
- 版本号统一为 0.4.0（程序 `__version__`、`pyproject.toml`、窗口标题、关于信息、启动日志）。

本版**未修改**抖音解析核心、FFmpeg 录制状态机、数据库 Schema 与已验收的 GUI 主要交互。

### 测试结果

- 完整自动化回归：**276 passed**（Windows / Python 3.12.16 / pytest 9.2.0，约 150 s）。
- 打包冒烟：真实 EXE 启动、标题显示 `v0.4.0`、最小化后主窗口隐藏且进程存活、关闭退出码 0、无 `DouyinLiveRecorder` / `ffmpeg` 残留。
- 图标验收：资源管理器、任务栏、托盘菜单、浅色 / 深色主界面、125% 缩放均取自打包 EXE 实际运行截图，未以 `.ico` 原图替代。
- 数据隔离：冒烟过程生成的 `data/` 已清除，压缩包不含任何用户数据，首次启动自动创建空数据目录。

### 安装与使用

1. 下载 `DouyinLiveRecorder-0.4.0-win64.zip` 并解压到任意目录（建议路径不含中文与空格）。
2. 双击 `DouyinLiveRecorder.exe` 启动；首次启动自动在 EXE 同级创建 `data\` 数据目录。
3. 在「添加直播间」中粘贴直播间链接，选择清晰度与保存目录即可开始录制。内置 FFmpeg，无需额外安装。
4. 关闭窗口默认最小化到系统托盘；托盘菜单「显示主窗口」恢复，「退出」彻底结束程序。

### 兼容性

- 仅提供 Windows x64（win64）构建，已在 Windows 11 上验证。
- 数据目录仍为 EXE 同级 `data\`，数据库 Schema 仍为 version 2（6 表）；配置键、录制目录、FFmpeg 路径解析、单实例互斥量名称均未变化，可与 0.3.1 及候选版沿用同一份数据。
- 从旧版升级：退出旧版本 → 解压新包到新目录（或替换旧目录中的程序文件，替换前请备份 `data\`）。
- 回滚：保留旧目录或旧版本压缩包即可回退，数据结构向后兼容。

### 已知问题

1. **P2-01（未修复）**：会话结束事件与分段结束事件字段混用，直播自然结束收尾时日志 / 状态栏可能出现「completed size=0」，与历史表（读数据库）不一致；数据库与录制文件不受影响。修复需变更事件契约，属录制核心范围，另行授权。
2. **托盘双击**：Windows 11 将托盘图标收进「隐藏的图标」浮层时，系统浮层不向图标转发双击，此时请通过托盘菜单「显示主窗口」恢复。
3. **可靠性待查**：FFmpeg 偶发未知退出码、解析侧 SSL 连接异常、风控验证页中断；现有证据不足以定性，未做根因推断。
4. 未覆盖低配机、4K 多屏、数小时长录与休眠唤醒场景。

**本版并未修复全部已知问题，请以上述列表为准。**
