## 7. 已接受并公开披露的工程风险

1. 本版未重新验证真实抖音直播录制链路（解析、拉流、断线续录、弱网）。
2. “异常后窗口空白”未复现、未消除。
3. FFmpeg kill 回退路径未完成专项实测。
4. 低配 Windows 设备（i3 / 4GB）未单独验收，仅有 2 核亲和性模拟基准。
5. 构建工具链尚未达到位级可复现。
6. LCEVC 相关第三方专利授权风险：`lcevcdec` 为 BSD-3-Clause-Clear，不授予专利许可，
   使用者需结合自身用途评估。

本版本不宣称所有潜在问题均已解决。
