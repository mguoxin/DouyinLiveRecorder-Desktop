## 6. 用户验收说明

### 6.1 版本与获取

- 版本：**0.3.0**
- 发布包：`release\DouyinLiveRecorder-0.3.0-win64.zip`（约 78 MB，解压后约 202 MB）
- 解压后得到 `DouyinLiveRecorder-0.3.0-win64\` 目录，直接运行其中的 `DouyinLiveRecorder.exe`，无需安装 Python 或 FFmpeg。

### 6.2 校验发布包（建议执行）

在解压前，用 PowerShell 计算并比对哈希：

```powershell
Get-FileHash .\DouyinLiveRecorder-0.3.0-win64.zip -Algorithm SHA256
```

结果应为 `D2891DFD553747B7FDD795E7598D720DB4FABED443088056E0D45E820138D883`。
也可对照 `release\SHA256SUMS.txt` 中的同名条目。

### 6.3 首次启动

1. 双击 `DouyinLiveRecorder.exe`；首次启动会在程序目录生成 `data\`（数据库、日志、录制文件）。
2. 建议把整个解压目录放在可写位置（不要放在 `Program Files` 或只读盘符），程序数据写在 EXE 同级目录。
3. 窗口标题显示 `抖音直播录制工具 v0.3.0` 即版本正确。

### 6.4 添加直播间

1. 点「添加房间」，输入直播间地址或房间号（例如 `476806339740`，或完整链接 `https://live.douyin.com/xxx`）。
2. 显示名称可留空，程序会自动使用房间号。
3. 需要修改时选中该行点「编辑房间」；删除房间不会删除历史记录与已录文件。

### 6.5 监控与录制

1. 选中房间行，点「开始监控」：列表“确认状态”为 `LIVE` 表示正在直播。
2. 勾选工具栏「自动录制」后，监控到直播开始会自动录制；也可选中行后点「开始录制」立即录制。
3. 「停止录制」结束当前文件并写入历史；「停止监控」只停止检测，不结束正在录制的任务。
4. 可同时监控多个房间：每个房间独立开始/停止，单个房间失败不会影响其他房间。

### 6.6 清晰度设置

1. 工具栏「设置」→「录制清晰度」，可选：OD（原画）/ UHD（超清，默认）/ HD（高清）/ SD（标清）/ LD（流畅）。
2. 目标清晰度不可用时，程序自动使用可用的更高档位，不会导致录制失败。
3. 修改后对下一次开始录制生效，不影响正在进行的录制。

### 6.7 Cookie 配置（可选）

1. 「设置」→「抖音 Cookie」：粘贴浏览器中登录后的 Cookie，点「保存」。
2. Cookie 用 Windows 本机加密保存，不写入数据库、日志，也不会显示已保存内容；重装或换 Windows 用户后需重新输入。
3. 出现解析风控提示时，可先「清除」Cookie 回到匿名访问，或重新导入新的 Cookie；Cookie 缺失或失效不会导致程序崩溃。
4. 若担心账号安全，可不配置 Cookie，程序默认匿名访问。

### 6.8 录制文件与数据位置

- 录制文件：`data\recordings\`（默认；可在设置中改到其他磁盘）
- 数据库与日志：`data\app.db`、`data\logs\`
- 断网超过约 15 秒后恢复时，同一直播可能续录为新的分段文件，均可正常播放。

### 6.9 备份与恢复

1. 「备份数据」生成一致性备份并校验完整性。
2. 「恢复备份」只登记请求，需要退出并重新启动程序才会替换数据库；恢复前会自动保留当前库的安全副本。
3. 备份与恢复都不会删除录制文件。

### 6.10 异常退出后的恢复

- 程序崩溃或被强制结束后重新启动：遗留录制记录会标记为 `interrupted` 并按磁盘实际大小回填；
- 程序自己启动的 FFmpeg 会被安全终止；无法确认归属的 FFmpeg 不会被结束（避免误杀其他软件）；
- 已录制的文件保留，可正常播放；历史中可见未完成的记录。

### 6.12 已知限制

- 未在 i3/4GB 真机上实测性能；低配机器的启动速度与多房间占用需你在目标设备上确认。
- 长时间（数小时以上）连续录制未做趋势验证；磁盘空间不足时程序会停止录制并标为失败，不会自动删文件。
- 解析依赖抖音公开接口，接口或签名变化时可能需要更新程序版本。
- 极端情况下（解析接口持续不可用）录制结束后收尾最长约 2 分钟才写入最终状态。
- 清晰度降级逻辑未在真实“缺档位”房间观察过。
