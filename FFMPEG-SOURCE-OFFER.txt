二、获取方式

方式一（推荐）：从本项目的 GitHub Release 附件下载
  https://github.com/mguoxin/DouyinLiveRecorder-Desktop/releases
  附件包括：SOURCE-ARCHIVES-SHA256SUMS.txt、SOURCE-MANIFEST.csv 及
  对应的 19 个源码归档（*.tar.gz）。
方式二：从公开上游按 SOURCE-MANIFEST.csv 中的精确提交/修订号取得
  （git clone 后 git archive，或使用对应仓库的归档接口；LAME 使用
  https://svn.code.sf.net/p/lame/svn/trunk/lame@7153）。
方式三：书面请求。在本仓库 Issues 提交标题为 “Source request: v0.4.1” 的请求，
  或通过仓库所有者公开联系方式提出。本项目承诺自本要约出具之日起三年内，
  在收到请求后提供上述源码归档与构建配方快照（可通过下载链接提供）。

三、关于重新链接

FFmpeg 及其静态链接的 LGPL 组件以独立 DLL 形式分发，用户可整体替换 DLL。
若需修改某个静态链接的 LGPL 组件并重新链接：
  - 使用上述源码归档中的组件源码与 recipe/ 中的构建脚本、补丁；
  - 工具链可使用任何兼容的 mingw-w64（BtbN 使用 mingw-w64 41eb042358、
    crosstool-ng、Ubuntu 构建镜像；这些版本已记录，但并非重新链接的必要条件）；
  - 本项目未修改任何组件源码，也未对 DLL 做二次修改。

四、不作出的承诺

1. 不承诺使用当前工具链可获得与发布二进制位级相同的输出。位级可重现
   不是 LGPL 重新链接义务的组成部分；本要约提供的是完整源码与构建材料。
2. 本要约不覆盖已撤下公开分发的 v0.4.0（其 FFmpeg 为第三方 GPLv3 静态构建，
